# Параметри Premium для Google Play

Рішення власника від 8 листопада 2026. Це підготовлена картка для внесення в Console, не підтвердження створення товару.

| Поле | Значення |
|---|---|
| Застосунок | com.intervalninaholosy.nmt |
| Product ID | premium_remove_ads |
| Тип | One-time product, звичайна покупка без строку дії |
| Назва українською | Premium — без реклами |
| Опис українською | Одноразова покупка для вимкнення реклами в застосунку. |
| Ціна для України | 29,90 UAH |
| Підписка, оренда, споживання товару | Не використовуються |

Власник вносить ціну та активує товар/пропозицію в Play Console. Перед збереженням перевіряє, що для України відображається саме 29,90 грн. Для інших країн слід переглянути локальні ціни, які пропонує Console, та доступність відповідно до доступності застосунку. Не вводити 29,90 як однакову суму в усіх валютах.

У коді не зашиваємо текст «29,90 грн»: BillingManager показує formattedPrice від Google Play, щоб відображення відповідало фактичній валюті та ціні покупки. Публічний RSA-ключ уже додано. Наявність ключа не означає, що товар активний або реальна тестова оплата пройшла.

Після налаштування повідомити «товар активний» або точний текст перешкоди в Console. Додати тестовий акаунт у License testing. Під час тестової оплати перевірити позначку тестової покупки; не надсилати purchase tokens у чат.

[Документація тестування Play Billing](https://developer.android.com/google/play/billing/test).
